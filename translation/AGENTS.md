# Codex 작업 규칙

- 번역 결과를 채팅으로 보고하지 않는다. 대상 파일(`translations/rest_priority_NNNN.tsv` 등)을
  직접 수정한다.
- 문제가 없는 한 사용자 입력을 기다리거나 멈추지 않고 번역을 계속 진행한다.
- 배치 최소 단위는 없다. 배치 크기는 자유롭게 정한다.
- `qa_structure.py`·`qa_glossary.py` 통과와 원문·문맥 직접 대조 검수는 항상 지킨다.
- 구조 오류가 반복 재현되거나 용어 충돌처럼 판단이 필요한 경우에만 멈추고 질문한다.

세부 절차는 `README.md`의 "신규 번역 배치 작업" 절을 따른다.
