HOW THIS MOD IS MAINTAINED (rule since 2026-09-26)
====================================================

ALL future local modifications to any installed mod must be expressed as
overrides inside THIS pak - never by repacking or editing upstream mod paks
again, unless the change cannot be expressed as a patch (removals, in-place
patch edits, binary assets).

Workflow: edit the source tree under
  translation\modpack-overhaul-repo\mods_src\female_overhaul\
then rebuild with:
  python translation\modpack-overhaul-repo\tools\repack_overhaul.py

female_overhaul - non-translation local fixes inventory
=========================================================

This pak consolidates every local non-translation override that can safely
share a single late load slot (the file is named zz_female_overhaul.pak so it
keeps the same late position the original zz_/999999200_ files used).

Bundled in this pak
-------------------

1) fu_copperarmor_price_fix (absorbed directory mod)
   - items/armors/biome/copperarmor/copperarmor.{chest,head,legs}.patch
   - Frackin' Universe replaces the vanilla /price of the three copper armor
     pieces with the string "500". The engine reads price as an integer, so
     item instantiation failed entirely. These patches only run when /price
     is still the string "500" (test + replace), so they stay harmless if FU
     ever fixes the source.

2) zz_modfix_refs (absorbed pak, previously mods/zz_modfix_refs.pak)
   - Repoints dangling asset references found during maintenance:
     * shpd_old/*: potion tooltip/object images pointed at removed icons.
     * professions/*.config, classes/default.config, ivrpg_specs/*.config:
       RPG Growth profession/class icon references repaired.
     * objects/sextoylegendary/sexbound_castingcouch: casting couch + cover
       images repointed to the existing sexbound asset.
     * projectiles/explosions/strong_cumexplosion: animation reference.
     * projectiles/sw_antimaterialround: spark impact animation reference.
     * interface/confirmation/gic_teleportconfirmation.config: reference fix.
     * items/WEAPONS/MELEE/{NPC_ONLY/gic_psionickatana,UNUSED_OLD/gic_chainsword}:
       weapon image references.
     * items/active/weapons/other/tentaclegun/shadowtentaclegun2: image ref.
     * objects/biome/alterash/ayaka/ct_ayaka_giant_tree: image reference.
     * items/active/weapons/ranged/abilities/{ctolight,kivlight_hellognio}:
       replacement icon pngs shipped as assets.

3) ffxiv_viera_blueprint_compat (absorbed pak, previously
   mods/999999200_ffxiv_viera_blueprint_compat.pak)
   - player.config.patch: adds the Viera racial blueprints (313 valid ones)
     to the shared player blueprint list so every race can craft them.
   - The earlier repack removed the three references that pointed at assets
     deleted in Viera 1.3.22 (vieratailoringcenter, crystallanternstickback,
     extravagantcurtainmed2).

4) splash screen restore (added 2026-09-27)
   - cinematics/splash.cinematic.patch
   - Galaxy_in_Conflict ships a full replacement /cinematics/splash.cinematic
     that swaps the opening image for its gic_splash.png logo and a WATCHER
     sound, which orphaned the "Cuter Chucklefish" mod's chuckles.png
     (the two-girls intro animation) even though that pak wins the
     chuckles.png file itself. This patch repoints /panels/1 back to
     /cinematics/chuckles.png:<frame> with 14 animation frames and restores
     /sfx/cinematics/fish_laugh.ogg (which Cuter Chucklefish overrides with
     its own audio). Guarded by a test on the gic_splash.png path so it is
     skipped entirely if GiC is ever removed.

Kept separate on purpose
------------------------

5) mods/gic_4_3_compat_fixes (directory mod, NOT merged)
   - Must load in the narrow slot right after Galaxy_in_Conflict core and
     before its addon paks (Weapons Pack, Escalate, Reskin): it creates the
     empty interactData.recipes arrays those addons append to, and restores
     one magazine asset still referenced by a deprecated pistol. A single mod
     cannot hold both that early slot and the late slot this pak needs, so it
     stays its own mod.

Translation-related (kept in the translation layer, not here)
-------------------------------------------------------------

- female_translation.pak           - Korean overhaul translation overlay
- zz_localeko_postload.pak         - late Korean translation fixes
- localeko_gic_legacy.pak,
  localeko_black_armory_legacy.pak - legacy Korean overlays
- -9998_trans_sbkor_0.98_structfix.pak - sbkor Korean patch, repacked to fix
  string-vs-array structure damage (translation pak, not an override)

- interface/title/kyterranmale.png, kyterranfemale.png: supply the species-select
  icons that satkyterran.species references but the Saturnians pak never shipped
  (upstream bug left its char-creation button invisible).

- interface/scripts/XGCS.lua: UTF-8-aware character iteration in
  rainbowifyText/gradifyText. The upstream Green's Dye Suite split each
  byte with a color tag, producing invalid UTF-8 on translated (Korean)
  dye names -> UnicodeException in TextPainter -> client kicked to title.

- sys/stardust/navext.lua: the StardustLib cockpit bar's SAIL and Teleporter
  buttons passed the nav console entity (or the player) as the pane's source
  entity. FU's newSail then failed its returnData handshake
  ("[FU] ERROR WHILE EXECUTING CUSTOM SAIL"), and the ship teleporter
  dialog got a non-teleporter source. The override resolves the nearest
  real techstation/teleporter object and binds the pane to it; with no
  tech station in range it falls back to the native OpenAiInterface.

- Starburst Rework (contents_3025139283) is listed as completely
  incompatible with FU: it loads after FU and silently replaces shared
  files. These restorations keep its content while returning the
  mechanics FU expects:
    stats/effects/{biomeairless,burning,electrified,tarslow,weakpoison,
      wet}.lua            - FU versions (FU race/status mechanics)
    stats/effects/{biomecold,biomeheat,biomeradiation,frostslow,glow,
      timefreeze}.lua, biomeheat.statuseffect - vanilla versions
    items/active/weapons/boomerang/boomerang.lua - FU version
    items/active/weapons/bossdrop/miniknoglauncher/rocketstack.lua - vanilla
    recipes/medicaltable1/healing/antidote.recipe - vanilla
    recipes/inventorstable{1,2,3}/{breath,radiation,cold,heat}
      protectionback.recipe.patch - FU-priced EPP inputs/groups; Starburst
      had broken the upgrade chain and gated them behind T2-T6 materials
    items/active/weapons/protectorate/*.png, bow/*full*.png,
      generic/produce/orange.png - FU art
  Left alone on purpose: universe_server requiredSystemWorlds - GiC
  intentionally removes it and rewrites the starter world (Starburst's
  own replace never applied anyway). Celestial/weather/biome tables are
  Starburst's intended overhaul surface and only affect new content.

  Second pass: 144 generated .patch files re-apply FU's values where a
  same-path Starburst op overwrote them, including:
    /builder on the 5 vanilla bows   - FU's neb-buildbow.lua
    /tooltipKind on ~130 weapons     - FU's per-type tooltip kinds
    /description on armor/backitems/food/materials - FU set-bonus and
      stat annotations were being hidden by Starburst flavor text
    /durability on 12 mining tools, /category on doomcannon, hylotl
      guard katana tiers, FU SAIL radiomessage texts

- interface/cockpit/{zoombutton,systeminfobutton}.frames.patch: undo
  MorePlanetInfo's frame-grid resize. The cockpit UI reverter wins the
  PNG (vanilla 13x26 / 99x42), so MPI's 26px/148px grid read frames
  outside the image bounds.
- music/Gario_EldritchSporeSpawn.ogg: alias for FU's
  Gario_EldrichSporeSpawn.ogg (sic, upstream filename has no 't').
  spicedMenuMusic_Frackin references the typo'd path in the title
  track list, so every title screen logged a missing-audio error.
- Repacked female_translation.pak, FU_KO_contents_3166424163.pak and
  -9998_trans_sbkor_0.98_structfix.pak: added 'test' guards ahead of
  each patch group so ops targeting keys removed by other mods
  (StardustLib mmupgrade layout, GiC crafting pane, Stardust quickbar,
  XRC's moved armor label, FU's renamed staff tier label, FU's
  20-box stat window) skip silently instead of logging errors.
  armor.itemdescription additionally mirrors the armor label into
  XRC's moved /subTitle node.

- ai/ai.config.patch: SAIL's upstream patch rewrites
  /scanlineAnimation/frames to "<image>:<index>" so its Lua can
  substitute the per-species portrait path, but OpenStarbound's native
  AiInterface never performs that substitution and requests literal
  /ai/<image>:0..13. Restore the concrete "scanlines.png:<index>" only
  when the placeholder is in place, so a future upstream fix wins.

- interface/configs/GDSuite.config.patch: Green's Dye Suite references
  /interface/close.png:1-3 for its close and four clear buttons, but
  that asset does not exist in the base game or the mod. Repoint all
  five buttons to the mod's own /interface/images/all/{x,xhover,xpress}
  .png (9x11, same size as vanilla /interface/x.png). Each button group
  is guarded by a test on the close.png:1 base path.

- weapons/crafted/tier1/xraiizy_scrapshotgun/
  xraiizy_scrapshotgun.activeitem.patch: the animation defines a
  middleFullbright part whose image is "<partImage>", but the item's
  animationParts has no middleFullbright entry. OpenStarbound resolves
  missing tags to the literal fallback "default", producing requests
  for /weapons/crafted/tier1/xraiizy_scrapshotgun/default. Add an empty
  middleFullbright part (same as the sibling xraiizy_scraprifle) only
  when the key is absent.

- terrestrial_worlds.config.patch: precursorracekrakoth_fupatch tries
  to append atprk_krakothoceanruins to
  /planetTypes/nitrogendeep/layers/subsurface/dungeons, but the
  nitrogendeep planet type is added by a later source's patch and its
  subsurface layer has no dungeons key, so the krakoth group silently
  skips. This pak now carries priority 999999800 so its patches apply
  after the nitrogendeep and krakoth patches; we create the missing
  dungeons array already containing the intended entry. If a future
  nitrogendeep/FU version ships the key itself, the inverse test skips
  this op and krakoth's own append works normally.

- _metadata priority 999999800: the pak name sorts mid-list
  (detection position ~514), so patches were actually applied BEFORE
  late-loading sources like the nitrogendeep and krakoth_fupatch paks.
  The explicit priority makes the intended "zz_ late slot" real - it
  lands just below female_translation (999999850).
